# ASUS RT-AX89X 監視テンプレート (Zabbix 7.0 日本語版)

ASUS のフラグシップ Wi-Fi 6 ルーター「**RT-AX89X**」（Qualcomm IPQ8074 Hawkeye SoC）を、Zabbix 7.0 LTS 環境で安全・軽量・高精度に監視するための **All-in-One テンプレート（日本語版）** です。

---

## 概要

単一のSSHマスターアイテムから全メトリクスを一括取得する高効率設計により、ルーターのリソース消費を最小限に抑え、監視処理起因のフリーズやハングアップを防止します。インポートするだけで、Wi-Fi 6 無線品質や全15基サーマルゾーン推移を含む **3タブ構成のモダンなテンプレートダッシュボード** が即座に利用可能です。

### 主な特徴
- **単一SSHマスターアイテムによる高効率データ収集**: 30秒に1回、単一セッション内で `top`, `uptime`, `loadavg`, `ping`, サーマル15ゾーン, `iwconfig`, `wlanconfig` を一括収集し、依存アイテムへJSON展開。
- **Wi-Fi 6 無線品質メトリクス**: 2.4GHz / 5GHz 別の接続端末数（整数表示）、平均電波強度（RSSI）、最小RSSI、平均SNR、フロアノイズを完全収集。
- **全15基サーマルゾーン自律ディスカバリ（LLD）**: CPU 4コア、NSS 2コア、SoC各部、無線PAなど全15基を自動検出し、日本語名を自動マッピング。熱異常や熱暴走リスクを未然に検知。
- **Zabbix 7.0 ネイティブ 3タブ・テンプレートダッシュボード内蔵**:
  - **タブ1: システム概要**: CPU使用率メーター、メモリ内訳Doughnut、Google Ping応答、詳細負荷推移
  - **タブ2: Wi-Fi 無線品質**: 端末数カード群、Wi-Fi 接続端末数推移（階段状描画）、Wi-Fi 電波環境推移
  - **タブ3: 各部温度推移 (全15基)**: 全サーマルゾーンのリアルタイム波形グリッド一覧

---

## 動作要件・前提条件

- **Zabbix Server / Proxy**: 7.0 LTS 以上（SSHチェック機能が有効であること）
- **対象機器**: ASUS RT-AX89X
  - ファームウェア: Stock Asuswrt または Asuswrt-Merlin
  - 管理画面の「管理」→「システム」で **SSH デーモン（SSH接続）を有効化** していること。

---

## 設定手順

1. `template_asus_rt_ax89x.yaml` を Zabbix 7.0 Web UI にインポートします（**「データ収集」→「テンプレート」→「インポート」**）。
2. 対象ホストを作成（または既存ホストを選択）し、テンプレート `ASUS-Router` をリンクしてIPアドレスを設定します。
3. ホストの **「マクロ」** タブを開き、以下のユーザーマクロを設定します。

| マクロ名 | デフォルト値 | タイプ | 説明 |
| :--- | :--- | :--- | :--- |
| `{$SSH_USER}` | `admin` | テキスト | ルーターのSSHログインユーザー名 |
| `{$SSH_PASS}` | (未設定) | シークレットテキスト | ルーターのSSHログインパスワード |
| `{$SSH_PORT}` | `22` | テキスト | SSHポート番号 |
| `{$CPU_UTIL_WARN}` | `80` | テキスト | CPU使用率警告閾値 (%) |
| `{$CPU_UTIL_CRIT}` | `90` | テキスト | CPU使用率重度障害閾値 (%) |
| `{$TEMP_WARN}` | `80` | テキスト | サーマルゾーン温度警告閾値 (°C) |
| `{$PING_TIME_WARN}` | `50ms` | テキスト | インターネット疎通Ping応答時間警告閾値 |
